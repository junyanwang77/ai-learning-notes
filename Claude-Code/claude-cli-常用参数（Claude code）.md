# Claude Code 命令行常用参数速查

> 说明:`claude` 命令的参数很多(完整列表可以运行 `claude --help` 查看),但日常真正用得上的其实只有一小部分。本文按"使用场景"分类,只挑最重要的讲,方便新手快速上手。

---

## 1. 最基础:直接对话

```bash
claude
```

不加任何参数,直接进入交互式对话界面——这是最常见的用法。

```bash
claude "帮我看看这个项目的结构"
```

后面直接跟一句话,作为你的第一条提问。

---

## 2. 会话管理:接着上次聊

| 参数                   | 作用                                       |
| -------------------- | ---------------------------------------- |
| `-c, --continue`     | 接着"当前目录下"最近一次的对话继续聊                      |
| `-r, --resume [关键词]` | 打开一个历史会话选择列表,可以恢复更早之前的某次对话               |
| `--fork-session`     | 恢复历史会话时,不覆盖原会话,而是新开一份副本(配合 `-r`/`-c` 使用) |

**什么时候用**:昨天跟 Claude 聊了一半的事,今天想接着聊,而不是从头再解释一遍背景,就用 `-c` 或 `-r`。

---

## 3. 脚本/自动化场景:让 Claude 当"工具"用

| 参数                      | 作用                                                         |
| ----------------------- | ---------------------------------------------------------- |
| `-p, --print`           | 非交互模式:直接输出结果然后退出,不进入对话界面。写脚本、管道调用时的核心参数                    |
| `--output-format <格式>`  | 配合 `-p` 使用,指定输出格式:`text`(默认)/`json`/`stream-json`,方便程序解析结果 |
| `--input-format <格式>`   | 配合 `-p` 使用,指定输入格式:`text`(默认)/`stream-json`                 |
| `--max-budget-usd <金额>` | 配合 `-p` 使用,给这次调用设置一个最高花费上限,超过就停止                           |

**什么时候用**:不是自己在终端里跟它聊天,而是想在脚本里"调用" Claude 去处理一批任务(比如批量总结文件、CI 流程里跑一次自动检查),这时候一定要加 `-p`。

---

## 4. 模型与"用脑程度"控制

| 参数                         | 作用                                               |
| -------------------------- | ------------------------------------------------ |
| `--model <模型>`             | 指定本次用哪个模型,可以用别名(如 `opus`、`sonnet`、`fable`)或完整模型名 |
| `--effort <级别>`            | 设置本次会话的思考强度:`low`/`medium`/`high`/`xhigh`/`max`  |
| `--fallback-model <模型...>` | 主模型不可用/过载时,自动按顺序尝试的备用模型(仅在 `--print` 下生效)        |

**什么时候用**:简单任务想更快更省,可以调低 effort 或换轻量模型;复杂任务想要更强的推理,可以调高 effort 或换更强模型。

---

## 5. 权限与安全控制(⚠️ 需要谨慎)

| 参数                               | 作用                                                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `--permission-mode <模式>`         | 设置权限模式:`manual`(逐步确认,默认更安全)/`acceptEdits`(自动接受编辑类操作)/`plan`(先规划后执行)/`bypassPermissions`/`dontAsk`/`auto` |
| `--allowedTools <工具...>`         | 明确允许使用的工具列表                                                                                              |
| `--disallowedTools <工具...>`      | 明确禁止使用的工具列表                                                                                              |
| `--dangerously-skip-permissions` | 跳过所有权限确认,**风险较高**,官方也只建议在没有网络访问的沙盒环境里用                                                                   |

**注意**:`--dangerously-skip-permissions` 意味着 Claude 可以不经过你确认就执行删除文件、跑任意命令等操作,普通开发环境不建议使用,只有在完全隔离、无外网的沙盒里才考虑。

---

## 6. 项目与上下文控制

| 参数                     | 作用                                                          |
| ---------------------- | ----------------------------------------------------------- |
| `--add-dir <目录...>`    | 允许 Claude 访问额外的目录(默认只能访问当前工作目录)                             |
| `-w, --worktree [名字]`  | 为本次会话新建一个 git worktree(独立的代码副本),适合"想让 Claude 大改动但不影响主分支"的场景 |
| `--mcp-config <配置...>` | 加载额外的 MCP 服务器配置(连接外部工具/数据源)                                 |
| `--settings <文件或JSON>` | 加载额外的 settings 配置                                           |
| `--agent <agent名>`     | 指定本次会话使用的 agent(覆盖默认配置)                                     |

---

## 7. 排查问题时会用到

| 参数                  | 作用                                                     |
| ------------------- | ------------------------------------------------------ |
| `--verbose`         | 输出更详细的过程信息                                             |
| `-d, --debug [过滤器]` | 开启调试模式,可选按类别过滤(如 `"api,hooks"`)                        |
| `--safe-mode`       | 临时禁用所有自定义配置(CLAUDE.md、插件、hooks、MCP 等),用于排查"是不是某个配置搞坏了" |
| `doctor`(子命令)       | 检查 Claude Code 安装/配置是否健康                               |

**什么时候用**:遇到奇怪的行为(比如某个自定义配置导致报错),先用 `--safe-mode` 排除是不是配置问题,再用 `--debug` 看具体日志。

---

## 8. 查看信息类

| 参数              | 作用       |
| --------------- | -------- |
| `-v, --version` | 查看当前版本号  |
| `-h, --help`    | 查看完整帮助文档 |

---

## 新手最该记住的 5 个参数

1. `-p` — 想让 Claude 当脚本工具用,而不是聊天,必须加这个
2. `-c` / `-r` — 想接着上次的对话继续,别每次都从头说一遍
3. `--model` — 想换个模型试试效果
4. `--add-dir` — Claude 说"访问不到某个目录"时,十有八九是没加这个
5. `--permission-mode` — 想调整"每一步是否要我确认"的松紧程度

其余参数(MCP、worktree、debug 相关等)属于进阶用法,遇到具体需求时再查也来得及,不用一开始就死记。
