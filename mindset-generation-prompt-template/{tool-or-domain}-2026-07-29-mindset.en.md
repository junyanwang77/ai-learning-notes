# AI Era Learning Map Generator

I want to understand **{Tool / Technology / Subject / Methodology / Domain}**.

Assume AI can perform almost all operational tasks for me. Therefore, do **not** begin with installation, commands, syntax, APIs, menus, or step-by-step tutorials.

Your goal is **not** to teach me how to use it.

Your goal is to help me build an accurate **Mental Model** and **World Model**, so I understand:

- What it is
- Why it exists
- When I should think of using it
- How it changes thinking, decision-making, and work
- Where it fits within the larger ecosystem

Generate a well-structured `README.md`.

## 1. Essence
- What is it fundamentally?
- Why does it exist?
- What problem does it solve?
- What did people do before it?
- What new possibilities does it create?

Focus on **Why**, not **How**.

## 2. World Model
Describe:
- Objects
- Actors
- State changes
- Workflows
- Systems
- Value

## 3. Concept Map
Organize the domain into 2–3 conceptual layers.

For each concept include:
- Entity
- Action
- Purpose
- Relationships

## 4. Decision Map
Instead of features, answer:

Situation → Decision → Reason → Expected Outcome

## 5. Search Space Expansion
Help me discover what I don't yet know to ask:
- Beginner questions rarely asked
- Questions experts ask
- Questions worth exploring next
- Questions that define mastery

Expand the search space rather than merely answering it.

## 6. Ecosystem
Explain:
- Upstream
- Downstream
- Alternatives
- Complements

## 7. Transferable Principles
Separate:
- First principles
- Transferable methodologies
- Implementation details
- Stable knowledge
- Changing knowledge

## 8. Minimum Mental Model
If I could remember only 10–20 concepts, which matter most?

## 9. Common Misconceptions
Explain:
- Common misunderstanding
- Why it happens
- Better mental model

## 10. Summary
Complete:

> What I truly gain is not ________, but ________.

## Output Requirements

Generate a maintainable `README.md`.

Use Mermaid whenever appropriate.

Prefer:
- Mind Maps
- Concept Graphs
- System Maps
- Dependency Graphs
- Decision Trees
- Lifecycle Diagrams

Assume AI performs the operational work.

Focus on:
- Mental Models
- World Models
- Decision Models
- Search Space
- Concept Relationships

rather than commands or procedures.
